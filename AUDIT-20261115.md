## Findings

### P1 - Async `NtDeviceIoControlFile` output is audit-only

The current NativeBridge records `STATUS_PENDING` as `unhandled` because completion may occur through APC, event or IOCP after the hook returns. The live Desktop session recorded 10 pending events with 0 sanitized. The native smoke verifies the probe result is classified and the isolated probe path is covered, but this is not proof that every asynchronous hardware read is rewritten.

Impact: asynchronous device queries can remain outside the profile-return-value guarantee.

Status: known limitation; do not mark hardware coverage complete.

### P1 - Physical host identity is not virtualized

The project does not make CPUID, XGETBV, physical BIOS/SMBIOS, TPM, DPAPI, NDIS, physical NIC firmware, kernel device objects or arbitrary kernel reads identical to another physical machine. The Native smoke proves supported user-mode probe surfaces only.

Impact: server-side or native checks outside covered user-mode APIs can still observe host-specific values.

Status: documented boundary; no claim of hardware equivalence is valid.

### P2 - Real Claude WMI usage was not observed

The real Desktop session produced no `wmi.install`, `wmi.get`, `wmi.async` or `wmi.sink` events. The independent WMI probe passed synchronous, property-enumeration, asynchronous and sink wrapping checks. This proves the wrapper works for the probe, not that Claude currently calls those paths.

Status: PARTIAL evidence, not a runtime failure.

### P2 - DNS evidence is runtime/socket evidence, not packet capture

The live session showed Claude only using the local MITM endpoint, the Relay using the SOCKS5 upstream, no Claude UDP endpoint, and SOCKS5 domain ATYP metadata. A packet capture of DNS traffic was not performed in this run; therefore the report does not claim an absolute zero-DNS-leak proof for every future child or library.

### P2 - Native audit command requires an explicit target

`npm run audit:native` without `-EnvName` exits with `profile-not-provided` and `native-audit-not-observed`. It is a Code Profile audit command; Desktop evidence must use `audit:desktop -Profile <name>`.

### P1 - Audit false positive fixed in working tree

`desktop-native-check.ps1` previously required rejected Chromium command-line proxy/DNS/QUIC/WebRTC switches. Claude `5.1231.2` refuses to start when those switches are present. The audit now rejects their presence and verifies NativeBridge runtime proxy evidence plus WFP instead. README documentation was updated to match.
