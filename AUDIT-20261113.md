It does not prove isolation from kernel callbacks, NDIS/WFP, driver device objects, DPAPI/Credential Manager, firmware, physical NIC state, or server-visible exit identity. CPU/XGETBV remains manifest-gated and was `not-configured` in the Desktop A/B run; no CPU hook is claimed by this report.

The clean network mode changes the process-local adapter/proxy view. It does not change Windows routing, VPN drivers, DNS transport, or the public exit IP. The browser shim currently covers the fields defined in each Profile persona; it does not invent a Chromium UA/UA-CH version when the persona leaves those fields unset.
